# Faria Rahman — Portfolio Website

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — visual design and responsive layout
- `script.js` — small navigation interaction

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `faria-rahman-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public website URL.

## Before publishing
Replace the placeholder LinkedIn and GitHub links in `index.html` with your actual profile URLs.

The content is based on the CVs provided for this portfolio. Verify dates, availability, contact details, and links before publishing.
